# Data

This folder contains the dataset used for the U.S. Organic Livestock Market & Regional Trends Analysis project.

The dataset contains information on organic livestock production across U.S. states and regions for multiple years.

## Data Preparation

The dataset was reviewed and organized before analysis. Data preparation included:

* Reviewing and cleaning column headers
* Organizing state and regional information
* Checking data consistency
* Preparing variables for analysis
* Creating additional analytical classifications where needed

The original dataset is retained separately from the analysis to maintain a clear distinction between raw data and processed results.
