# U.S. Organic Livestock Market & Regional Trends Analysis

## Project Overview

This project analyzes U.S. organic livestock data to identify regional patterns, changes in livestock production, and differences across states and regions.

The analysis focuses on organizing, cleaning, and exploring livestock data to generate meaningful insights that could support understanding of organic livestock production trends.

## Objectives

* Clean and organize the livestock dataset.
* Analyze organic livestock production across U.S. states and regions.
* Compare livestock categories across different years.
* Identify regional patterns and changes.
* Use statistical analysis to generate meaningful insights.
* Present findings using clear data visualizations and summaries.

## Tools & Skills

* Google Sheets
* Data Cleaning
* Data Analysis
* Data Visualization
* Statistical Analysis
* Excel/Spreadsheet Functions
* Conditional Logic
* COUNTIFS
* Lookup Functions
* Data Classification

## Key Questions

* Which regions have the highest levels of organic livestock production?
* How has livestock production changed over time?
* What differences exist between states and regions?
* What patterns can be identified from the data?

## Project Outcome

The project demonstrates how spreadsheet-based data analysis can be used to transform a raw dataset into structured information and meaningful insights.

The analysis also strengthened my ability to clean datasets, apply analytical functions, classify data, compare groups, and communicate findings.
