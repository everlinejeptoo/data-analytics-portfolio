# Visualizations

This folder contains visualizations created during the analysis of U.S. organic livestock production.

The visualizations are designed to communicate:

- Regional differences in organic livestock production
- Changes in livestock production across years
- Differences between livestock categories
- Patterns identified during exploratory analysis

## Purpose

Visualizations were used to make the analytical findings easier to interpret and communicate.

Additional charts and visual outputs will be added as the project develops.
