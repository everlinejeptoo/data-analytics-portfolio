# Data Analysis

## Analysis Approach

This project uses a structured data-analysis workflow to examine U.S. organic livestock production across states and regions.

The analysis began with data cleaning and organization, followed by classification, exploratory analysis, probability calculations, and comparisons across livestock categories and years.

## Data Cleaning

The dataset was reviewed and organized to ensure that the variables were clearly labeled and suitable for analysis.

Key fields included:

- State
- Region
- Beef livestock
- Milk livestock
- Total livestock
- Production year

## Regional Classification

States were grouped by geographic region to support regional comparisons.

Additional classifications were created to examine differences in regional characteristics and livestock production patterns.

## Exploratory Analysis

Spreadsheet functions were used to explore the dataset and identify patterns.

Functions included:

- COUNTIF
- COUNTIFS
- SWITCH
- IFS
- HLOOKUP
- VLOOKUP

These functions supported classification, conditional counting, and information retrieval.

## Probability Analysis

Empirical probability was used to examine the likelihood of selected characteristics occurring within the dataset.

This provided another way to understand the distribution of organic livestock production.

## Comparative Analysis

Livestock production was compared across years, states, and regions to identify changes and patterns.

The analysis also examined differences between livestock categories.
