# Climate Data Trend Analysis Using Linear and Polynomial Regression

## Project Overview

This project examines historical climate data from 2000 to 2020 to identify trends and relationships among key climate indicators.

The analysis uses statistical techniques and data visualization to explore patterns in CO₂ concentration, temperature anomaly, sea-level rise, Arctic ice extent, and global emissions.

A key focus of the project is comparing linear and polynomial regression models to determine which approach best represents the patterns observed in different climate variables.

## Project Objectives

- Explore trends in historical climate data.
- Examine relationships between climate variables.
- Apply linear regression to identify trends.
- Apply polynomial regression to model nonlinear patterns.
- Compare model performance using R².
- Analyze residuals to evaluate model fit.
- Use data visualization to communicate findings.
- Interpret statistical results in a real-world context.

## Dataset

The dataset covers the period from 2000 to 2020 and includes several climate-related variables:

- Year
- CO₂ concentration
- Temperature anomaly
- Sea-level rise
- Arctic ice extent
- Global emissions

## Methodology

### 1. Data Exploration

The dataset was first reviewed to understand the variables, their ranges, and the patterns present over time.

### 2. Trend Analysis

Scatter plots and trend lines were used to examine how individual climate indicators changed over the study period.

### 3. Linear Regression

Linear regression was used to model variables that demonstrated approximately linear relationships over time.

The model was evaluated using the coefficient of determination (R²) to assess how well the model explained variation in the data.

### 4. Polynomial Regression

Polynomial regression was used for variables where the relationship appeared nonlinear.

The polynomial model was compared with the linear model to determine whether the additional complexity provided a better representation of the observed pattern.

### 5. Residual Analysis

Residuals were examined to evaluate the difference between observed values and model predictions.

Residual analysis helped assess how well each regression model represented the underlying data.

## Key Learning

This project demonstrated that different datasets may require different statistical models.

Variables that follow a relatively consistent pattern over time can often be represented effectively using linear regression, while variables showing curvature or changing rates of growth may be better represented using polynomial regression.

The project also reinforced the importance of evaluating model performance rather than selecting a model based only on visual appearance.
